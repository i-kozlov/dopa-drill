# Допа-дрилл

Игровой тренажёр арифметики с русским интерфейсом. С каждым решённым заданием музыка, анимация и праздничные эффекты становятся ярче. Игра работает в браузере.

Маскот Допакичи переносит введённые цифры и радуется правильным ответам. Ошибки можно исправить: они не приводят к проигрышу и не уменьшают интенсивность праздника.

## Что умеет игра

- 58 вычислительных навыков по программе японских 1–6 классов: сложение, вычитание, умножение, деление, вычисления в столбик с промежуточными шагами, десятичные и обыкновенные дроби, проценты, отношения и поиск неизвестного числа. Номера классов обозначают программу исходного проекта, а не точное соответствие российской школьной программе.
- Режим «Мой уровень» с первоначальной проверкой знаний и постепенным открытием новых тем.
- Выбор класса, тренировка конкретного навыка, повторение ошибок и дерево навыков.
- Звёзды за освоение навыков, ежедневные задания, награды, коллекция фонов, музыки и костюмов, календарь занятий.
- 100 очков за завершение основного раунда. Если не менее 80% заданий решены без ошибок с первой попытки, открывается бонусный раунд на время с дополнительными очками.
- Музыка и звуковые эффекты синтезируются через Web Audio API: аудиофайлы не нужны.
- Поддержка вертикального экрана смартфона и компьютера. Можно отвечать цифровыми клавишами и стирать ввод клавишей Backspace.
- Настройка числа заданий (6, 10 или 14), громкости и интенсивности эффектов. При интенсивности 0% отключаются движение, тряска, вспышки и конфетти.
- Все результаты хранятся локально в браузере через localStorage и не отправляются на сервер.

## Как меняется сложность

Подходящее название этой функции — **настройка сложности**. Автоматический подбор заданий под ученика называется **адаптивной сложностью**.

В игре сложность определяется темами и уровнем освоения:

- **«Мой уровень»** сначала проверяет знания: правильные ответы ведут к более сложным темам, ошибки уменьшают шаг продвижения. После проверки режим сочетает повторение освоенных тем с изучением доступных новых навыков.
- **Кнопки 1–6 классов** задают учебный диапазон. Основной раунд движется от более простых тем выбранного класса к более сложным. С седьмого задания бонусного раунда используются начальные темы следующего класса; для шестого класса диапазон не меняется.
- **Дерево навыков** позволяет выбрать доступную тему для тренировки. Нажатие на освоенный навык открывает его статистику и условия получения следующей звезды.
- **Повторение** возвращает задания, в которых были ошибки.

Обычно для освоения навыка нужно выполнить не менее шести заданий и решить без ошибок, включая промежуточный ввод, хотя бы пять из последних шести. Следующая тема открывается после освоения всех её предварительных навыков. Во время первоначальной проверки знаний действует отдельное правило: чистый ответ может сразу засчитать проверяемый навык и его предварительные темы. Одна ошибка не отменяет уже полученное освоение.

Интенсивность анимации регулирует эффекты. Математическую сложность меняют выбором класса, темы или режима «Мой уровень».

### Где разработчику менять параметры

- `app/js/skills.js`: темы, классы, предварительные навыки, параметры генераторов (диапазоны чисел, число цифр, переносы и заимствования), а также `MASTERY` — правило освоения.
- `app/js/problems.js`: генерация примеров, условия отбора, шаги ввода и подсказки.
- `app/js/session.js`: подбор тем для классов, адаптивного режима и начальной проверки; условия получения звёзд.
- `app/js/scoring.js`: очки, рост допа и время на продолжение комбо. Изменение этих параметров влияет на темп игры и награды.

Текущие границы тем подробно описаны в `docs/curriculum.md`, общие правила — в `docs/SPEC.md`. Эти подробные документы пока на японском языке.

## Локальный запуск

Сборка и установка зависимостей не требуются. Достаточно Python 3: из корня репозитория запустите статический сервер для каталога `app/`.

```bash
python3 -m http.server 8000 -d app
```

Откройте `http://localhost:8000/` в браузере. Прямое открытие через `file://` не подходит: игра использует ES Modules.

## Публикация на GitHub Pages

GitHub Pages подходит: игра состоит из статических файлов и не требует серверной части, базы данных или секретных ключей.

Простой способ публикации исходного репозитория:

1. Отправьте изменения в ветку `main` на GitHub.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем сохраните настройку.
4. После завершения публикации откройте `https://i-kozlov.github.io/dopa-drill/app/`.

Для форка замените владельца и название репозитория в адресе. Настройка Pages и её доступность для закрытых репозиториев зависят от тарифа GitHub.

Если нужен адрес без `/app/`, используйте GitHub Actions для публикации содержимого каталога `app` как артефакта Pages. Другой статический хостинг тоже подходит: публиковать нужно содержимое `app/`, без этапа сборки.

Сохранения привязаны к браузеру и адресу сайта. Прогресс с локального запуска не переносится на опубликованный сайт автоматически; общей учётной записи и синхронизации между устройствами нет.

## Тесты

Используйте современную версию Node.js 20 или новее. Проверено на Node.js 24.

```bash
node --test tests/*.test.mjs
```

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `app/` | Игра: ES Modules без сторонних библиотек |
| `docs/SPEC.md` | Подробная спецификация |
| `docs/curriculum.md` | Учебные темы, генераторы и дерево навыков |
| `docs/dopakichi.svg` | Исходный рисунок Допакичи |
| `tests/` | Автоматические тесты |
| `tools/build_fonts.sh` | Пересборка японских подмножеств шрифтов; для русского интерфейса не требуется |

Русский интерфейс использует системные шрифты с поддержкой кириллицы. Названия навыков и видимые строки переведены; вычислительные правила и идентификаторы сохранений сохранены.
